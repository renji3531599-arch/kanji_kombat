# Kanji Kombat

漢検の級別難易度で「読みだけ」を競う、リアルタイム風オンライン漢字バトルのプロトタイプです。

## Run

```bash
npm run dev
```

ブラウザで `http://localhost:4173` を開きます。依存パッケージなしの静的アプリです。

## 実装済み

- 1級〜10級・準1級・準2級の12段階の級選択
- 各級500問の出題プール（著作した読み・意味カードをプロンプト違いで展開）
- ひらがな／カタカナの読みだけを受け付ける回答判定
- 15秒タイマー、5問対戦、相手のリアルタイム回答表示、スコア、勝敗、レート・XP
- 正解後に正しい読みと意味を両者へ公開するリビールカード
- ランクマッチ、クイックマッチ、フレンドルーム（ルームコード発行・参加・コピー）
- ソロトレーニング、回答履歴、シーズンランキング、通知、プロフィール
- `localStorage` に進捗・レート・対戦履歴を保存
- PC・タブレット・スマートフォン向けレスポンシブUI

問題カードの級別基準・字数表示はユーザー指定の漢検目安に合わせています。問題文と意味はアプリ内データとして管理しています。
