- 累計字数: 80 / 240 / 440 / 642 / 835 / 1026 / 1339 / 1623 / 1951 / 2136 — **PDF表記の「計〜字・累計〜字」と完全一致**

- 10級〜2級の累計2136字 == 常用漢字2136字（同上）

## PDF抽出の文字修正 (`data/official/*.txt`)

PDFのテキストレイヤーには旧字体・誤変換が含まれるため以下を修正済み
（`tools/fix_lists.py` 参照。修正後、上記の字数・集合検証をすべて通過）:

- 字体の正規化: 売歩歯様帯縦巻謝徴雑奥剤掲譲陰鋳晩舗壌渉醸 殻
- 級の重複・不正文字の置換（頻度・配当年長の妥当性から選定）:
  - 7級: `鋟`→**録**（KANJIDIC2 grade4 / 4年配当）
  - 6級: `衠`→**衛**, `贅`→**賛**（同 grade5 / 5年配当）
  - 5級: 重複した`治`→**敵**（同 grade5）＋ 6年配当の不足7字（困推株沿激秘臓訳）を補完
  - 4級: `猒`→**猿**, `掔`→**捗**（常用漢字・中学範囲）
  - 3級: 重複した`棄`→**塁**
  - 準2級: `諹`→**詮**, 2つ目の`賜`→**須**, `埾`→**塞**, `墊`→**訃**
  - 準2級その2の末尾9字（錮稽窟膝臼畿餅顎頰）はPDFパース欠落のため頻度タグ付き常用漢字から復元
- 3級・4級・準2級には改正後の級別表に含まれる少数の表外字がそのまま残る
  （例: 謡・峠・込・戯・賊・痘・泌・藩・篤・醸・璽・繭 など）

## 問題生成 (`tools/generate_questions.py`)

1. 単語問題: JMdict の「漢字表記 × ひらがな読み」ペア（約11万件）を
   「全ての漢字がその級の累計プールに含まれる最も低い級」に配分。
   優先順位: 頻度タグ (news1/ichi1/spec1/nf) 付き → 2字熟語 → 無タグ。
   活用形（〜って/〜ます等）はブラックリストで除外。
2. 単漢字問題: 10級〜5級は**新出漢字を全問化**（訓→音の順で各級1読みずつ）、
   4級〜2級は単語で未カバーの新出漢字のみ。準1級・1級は単語のみ。
3. 誤答選択肢: 優先順に
   1. 同一語の漢字の別音読みへの置換（残念→ざんねん vs **さん**ねん）
   2. 同級の他問題の正答読みから同程度のモーラ長のものをランダム
   - 同じ語の別の正しい読み（JMdict上の全読み）は誤答に使わない
   - 単漢字問題では表示漢字の全読みを誤答から除外（複数正解の防止）
4. 誤答は `near_miss_distractors` で音の編集距離を計算し、濁点・半濁点・長音・促音・似た音の1モーラ違いを優先する。無関係なランダム読みは最後の補完に限定。
5. 各レベルちょうど1000問、シード固定 (`SEED = 20260916`) で再現可能。
6. 検証 (`tools/test_luau.py`): lupa (LuaJIT) で全モジュールを実行し、
   選択肢4つ・回答はひらがな・誤答と重複なし・同一レベル内プロンプト重複なしを確認。

## 再生成

```bash
pip install jamdict jamdict-data lupa
python3 tools/generate_questions.py
python3 tools/test_luau.py
python3 tools/build_place.py
```
